# StudyNotion - EdTech Platform 🎓

StudyNotion is a fully functional EdTech platform that enables students to consume educational content and instructors to create and sell courses.

## 🚀 Tech Stack

- **Frontend:** React.js, Vite, Tailwind CSS, Redux Toolkit
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas & Mongoose
- **Cloud Storage:** Cloudinary (for thumbnails & media)
- **Payment Gateway:** Razorpay
- **Mailing:** Nodemailer (SMTP)
